# きくまど

保護者のための AI 相談窓口のデモです。講義の発表（2〜3 分）で見せるために作りました。

## どんなもの？

中学校の保護者が、スマホから質問や相談を送る窓口です。AI が最初に受け答えをして、先生の負担を減らします。

- 簡単な質問: 学校の情報をもとに、AI がその場で答える
    - 先生への連絡はしない
- 本格的な相談: AI が話を聞き取り、先生向けのまとめを作る
    - 保護者が中身を確かめてから送る
    - まとめの項目: 学年 / 分類 / 緊急度 / 要約 / 希望
    - いじめ・けがなど安全に関わる相談は、緊急度「高」で優先して届ける

## ファイル

| ファイル | 中身 |
|---|---|
| `きくまど.html` | 台本どおりに動くデモ。発表ではこちらを使う |
| `きくまど_本物のAI.html` | Google の Gemini が本当に返事をする版 |

## 開き方

- ファイルをダブルクリックすると、ブラウザで開きます
- インターネットへの公開や、インストールは要りません
- 発表では、ブラウザを全画面にすると見やすくなります
    - Mac の Chrome: `control` + `command` + `F`

## 台本のデモ（`きくまど.html`）を動かす

開くと表紙が出ます。クリックするたびに、会話が 1 つずつ進みます。

| したいこと | 操作 |
|---|---|
| 次へ進む | クリック ／ スペース ／ → |
| 1 つ戻る | ← |
| 最初からやり直す | R |
| 場面へ飛ぶ | 1（簡単な質問） ／ 2（いじめの心配） |
| 左下の操作ヒントを隠す | H |

- AI が文字を打っている途中でクリックすると、その発言がすぐに最後まで出ます

## 本物の AI 版（`きくまど_本物のAI.html`）を動かす

- 最初に開くと、会話の中に API キーを入れる欄が出ます
    - API キーは Google AI Studio で作ります
    - キーはこのパソコンのブラウザの中だけに保存されます。ファイルには書かれません
- 下の入力欄に文字を打って、Enter で送ります
    - 改行したいときは Shift ＋ Enter
- 左下に発表者向けのパネルが出ます
    - ボタン: 会話をやり直す ／ API キーを変える
    - Esc キーで隠したり出したりできます
    - パソコンの広い画面のときだけ出ます
- 実在の人の名前や、本当の相談内容は入れないでください

### うまく動かないとき

画面にエラーが出たら、「詳しい内容」の部分を見てください。

| 出てくる言葉 | 原因と直し方 |
|---|---|
| `free tier is not available for this project` | その Google アカウントでは無料で使えない。Google AI Studio で支払いの設定をするか、別のアカウントでキーを作る |
| `API_KEY_INVALID` | キーの打ち間違い。「API キーを変える」から入れ直す |
| `429` | 使える回数を超えた。1 分ほど待ってから送り直す |

- 当日に AI が動かなくても、台本のデモがあれば発表はできます

参照 → Google AI Studio: https://aistudio.google.com/

## 言葉や色を変える

どちらのファイルも、上の方に「ここから〜です」と書かれた部分があります。変えてよいのはその部分だけです。

- VS Code やテキストエディットで開いて書きかえます
- `` ` ``（バッククォート）で囲まれた中の文字を書きかえます
    - 改行したいところは、そのまま Enter で改行して OK
- `` ` `` や `{ } [ ] ,` は消さないでください
- 書きかえたら保存して、ブラウザで開き直すと反映されます

### 変えられるもの

- `きくまど.html`
    - `設定`: 窓口の名前・学校の名前・ボタンの言葉など
    - `色`: 画面の色（`#3949ab` のような 6 けたの記号）
    - `台本`: 会話の中身。場面ごとに日付・時刻・会話を書く
- `きくまど_本物のAI.html`
    - `設定`: あいさつ・送ったあとの返事・緊急のときの案内など
    - `学校の情報`: AI が簡単な質問に答えるときに使う情報。ここに無いことは、AI は答えずに先生へ回す
    - `色`: 台本のデモと同じ

### 台本の 1 行の種類

| 書き方 | 画面に出るもの |
|---|---|
| `` { AI: `...` } `` | AI の発言 |
| `` { 保護者: `...` } `` | 保護者が入力して送る発言 |
| `` { 保護者が選ぶ: `...` } `` | 直前の AI の選択肢から 1 つを選ぶ |
| `{ まとめ: { ... } }` | 先生向けのまとめのカード |
| `` { 保護者が押す: `...` } `` | まとめのカードのボタンを押す |
| `` { お知らせ: `...` } `` | 画面の真ん中に出るお知らせ |

- AI の発言には、`選択肢`（選べる候補）や `出典`（答えのもと）を付けられます
- 書き方はファイルの中のお手本をまねすると安全です

### 壊れてしまったら

- 画面が真っ白になったら、消してはいけない記号を消した可能性が高いです
- 書きかえる前に、ファイルをコピーして控えを取っておくと安心です
